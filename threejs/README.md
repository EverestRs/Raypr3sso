# 雨の夜 ・ 街角のよるマート

一个雨夜便利店街角的三渲二（卡通渲染）微缩三维场景，基于 Three.js（r147，已本地内嵌，可完全离线运行）。

## 运行方式

**方式一：直接双击打开** `index.html`（所有依赖已内嵌，无需网络、无需服务器）。

**方式二：本地服务器**

```bash
cd threejs
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 操作

- 左键拖拽 —— 旋转
- 滚轮 / 双指捏合 —— 缩放
- 右键拖拽 —— 平移

无任何 UI 界面元素。

## 场景内容

- 方形展示底座 + 铭牌，日式便利店街角一角
- 便利店：大面积玻璃橱窗、发光主招牌、闪烁的拐角竖招牌、雨棚、自动门（会开合）、
  门口地垫、贩卖机 ×2、自行车、伞架、垃圾桶、立牌、公告栏
- 店内：靠墙货架与商品、中岛货架 ×2、发光饮料柜、便当柜、关东煮柜台、
  收银台 + 咖啡机、杂志架、海报、吊旗、地贴导视
- 街道：马路 + 斑马线 + 车道线 + 停车位、路缘石、排水沟与格栅、点字导盲砖、
  路灯、电线杆与电线、红绿灯（会变色）、凸面镜、路名牌、护栏、花坛与小树、
  邻楼、后巷栅栏与垃圾桶、井盖、多处积水洼
- 路边停放车辆：AE86（白黑熊猫涂装 + 「藤原とうふ店（自家用）」车门贴）停在右侧路
  停车框内；FC3S RX-7（白色楔形车身 + 闭合跳灯 + 全宽尾灯）停在店前路缘
- 动效：持续降雨、地面溅落水花、积水涟漪、屋檐滴水、玻璃雨水滑落、
  湿地灯光倒影池、招牌与灯箱闪烁、自动门开合、红绿灯变换
